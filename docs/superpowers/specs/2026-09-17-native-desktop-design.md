# 采图台原生桌面客户端方案

状态：用户已确认本方案并要求开始实施。

## 目标

运行项目后直接打开独立桌面窗口，任务管理和图片浏览不依赖外部浏览器或嵌入网页。支持苹果和微软桌面系统；不制作安装包，不重写已有采集引擎。正常采集保持静默，登录和验证仍由用户主动打开专用浏览器处理。

## 方案选择

1. 推荐：Python + PySide6 原生控件界面，复用现有 Node.js 后台。
   中文说明：用桌面图形界面库实现窗口和控件，继续使用原有采集运行环境。无需给界面再加入浏览器内核，但开发运行时需同时具备两套语言运行环境。
2. 备选：网页技术实现独立桌面窗口。现有页面复用更多，但与用户想要的原生项目软件形态不如第一种贴近；本轮不采用。
3. 不采用：把采集、任务和下载引擎全部重写为 Python。工作量与回归风险显著增加，对获得独立窗口没有必要。

桌面库依据官方入门和托盘文档选择：

- https://doc.qt.io/qtforpython-6/gettingstarted.html
- https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QSystemTrayIcon.html

## 首版窗口

一个主窗口，左侧三个入口：任务、图片、设置。使用系统原生桌面控件及简洁的中文界面，不加载现有网页充当窗口内容。

### 任务

- 主页链接输入、文件导入、内置名单预览、默认一年和自定义时间范围。
- 任务列表、筛选、分页、勾选批量开始和删除；删除只影响任务记录，不删除图片。
- 开始、取消、失败重试、图片补采、采集新增、全局暂停和继续。
- 清楚展示运行、等待登录、冷却、失败、部分完成、已完成等状态，以及已保存和失败图片数量。
- 登录和验证继续复用现有专用浏览器，只在明确点击后显示。

### 图片

- 浏览已经下载到当前图片根目录的账号图片，而非重新加载平台远程图片。
- 缩略图按页加载；选中后在软件内查看已保存的完整图片，支持适应窗口、原始比例和缩放。
- 保持宽高比，不以正方形裁切图替代完整预览；显示文件名和实际像素尺寸。
- 提供打开文件所在目录，不提供图片删除或编辑功能。
- 切换账号或关闭窗口时取消过期缩略图任务，并限制缓存大小，避免一次载入所有原图。

### 设置

- 查看后台连接状态、数据目录、图片目录和依赖检测结果。
- 设置默认采集周期与关闭窗口行为；默认周期仍为一年。
- 允许为后续启动选择图片保存目录；已有后台运行时不偷偷切换目录、不移动旧图片，提示需要安全停止并重启后生效。
- 数据目录默认复用本项目现有目录，首版不提供在线迁移或更换数据目录，避免遗失历史任务。
- 默认不创建登录自启项，不安装系统常驻服务。

## 窗口和后台生命周期

- 桌面入口先检测后台；已有实例则连接，没有实例则由现有后台命令启动，启动过程不弹浏览器。
- 启动后台继续沿用现有恢复策略：用户之前已启动但未完成的任务可恢复；待开始任务不会自动开始。开发验证仅使用临时数据，不运行用户真实队列。
- 同一数据目录只允许一个桌面实例；再次启动唤起原窗口。继续沿用后台自身的单实例锁，不按进程名查杀。
- 默认关闭按钮隐藏到托盘或菜单栏，并在第一次关闭时说明后台继续运行；若系统没有可用托盘，提供明确选择，不把窗口藏到无法找回的位置。
- 菜单分别提供“显示主窗口”“暂停/继续”“仅退出界面”“退出并停止采集”。明确停止必须等待原后台完成进度保存和资源关闭，失败则保留界面并提示。
- 原微软脚本托盘保留兼容，但新桌面版启动说明不要求同时运行它，避免出现两个操作入口。
- 电脑休眠不强制阻止；不承诺休眠期间采集，不承诺零资源占用。

## 边界和数据流

- 桌面模块分为入口、窗口/页面、后台客户端、本地图片读取、设置与托盘，避免一个大文件承载全部逻辑。
- 调度、采集、下载、断点、图片去重索引仍由后台唯一写入，桌面端不直接改任务文件。
- 任务操作通过现有本机接口完成；后台启停和身份确认复用已有控制命令。命令参数独立传递，不拼接执行外壳脚本，不把凭证写入界面或普通日志。
- 网络请求、后台命令、目录扫描和图片解码不得同步阻塞窗口线程。可见窗口即使暂停也保留低频状态检查；操作后立即刷新，避免外部操作与界面不同步。
- 后台状态补充必要的实际目录信息，桌面端使用后台确认的目录，不信任任意任务记录里的绝对路径。
- 图片读取仅限确认的根目录内；检查路径边界及符号链接，跳过临时、损坏和非图片文件，不接受远程图片地址。
- 旧网页入口暂留为兼容和诊断入口，不是新软件正常使用的前置条件。

## 随桌面化修复的已确认问题

- 任务状态写盘失败：完整捕获异步错误并释放调度占位；写盘不可用时停止继续调度，保留已落盘数据，明确提示存储故障，不在故障期间无限重试。
- 多入口状态不同步：新桌面端状态刷新不依赖“上一次是否有运行任务”，旧网页补充低频检查，确保托盘或其他入口操作后可更新。
- 不在本轮扩展为自动重启守护、云同步、备份系统或平台验证绕过。

## 验收

1. 在本机运行项目，出现真正桌面窗口；正常操作不打开外部浏览器、不加载嵌入网页。
2. 创建任务只进入待开始，任务各操作与现有后台语义一致；默认一年，历史数据不变。
3. 以隔离数据验证界面关闭后后台继续、窗口重新打开后连接原实例、安全退出后停止完成。
4. 本地完整图片保持原比例展示，缩略图与大图分离；损坏文件、超大图与大量图片不拖住主界面。
5. 补充窗口行为、客户端超时、后台失联、目录边界、状态同步、存储故障和设置持久化测试；现有自动化测试全部通过。
6. 本机苹果系统实测窗口交互；微软系统增加自动化覆盖并列出仍需实机验收的托盘与关闭行为，不把静态检查视为原生实机通过。
7. 提供直接运行项目的苹果和微软入口及依赖安装说明，不生成安装包；完成代码使用中文提交说明提交。

## 本轮不做

独立安装包、自动升级、云端服务、跨电脑自动同步、图片编辑/删除、全量引擎重写、自动破解登录验证、隐式安装登录自启项。
