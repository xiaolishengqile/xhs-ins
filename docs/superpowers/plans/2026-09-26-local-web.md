# 本机网页管理实施计划

**目标：**用本机网页承载任务、图片和设置，保证普通采集静默，保留独立后台。

**结构：**沿用现有任务后台及网页入口；增加图片与设置模块、安全停止入口；删除原生桌面运行层。

**技术：**Node.js 22、原生网页脚本、Playwright 采集、Sharp 缩略图。

**依据：**`docs/superpowers/specs/2026-09-26-local-web-design.md`

## 任务

1. **静默采集契约。**先增加浏览器资源测试，验证采集始终隐藏、只有显式登录可见；再收紧浏览器启动参数；运行单测。
2. **本地图片接口。**先增加隔离图片目录的接口测试，覆盖分页、缩略图、原图、路径越界、符号链接、大小与损坏文件；实现独立图片库和接口；运行集成测试。
3. **设置与停止接口。**先增加设置持久化、当前目录不变、下次启动目录生效和停止时序测试；实现设置存储及后台安全停止接线；运行集成测试。
4. **网页与启动入口。**先增加端到端测试，覆盖三入口、图片浏览、保存设置、停止提示；实现界面和跨系统启动脚本；更新说明，移除原生桌面层及其流水线；运行端到端测试。
5. **完成前验证。**运行项目完整测试、脚本检查和隔离后台烟测；复核差异和真实数据目录未变；中文提交完整功能。

## 主要风险检查

- 图片读取受目录符号链接和文件替换影响时必须拒绝越界。
- 页码、账号或文件名异常时返回明确错误，不让服务崩溃。
- 保存目录设置不会在运行中偷偷切换或移动旧图。
- 网页停止请求不能等待自身连接关闭造成死锁。
- 无显示环境下采集不能因外部变量变成可见窗口。
