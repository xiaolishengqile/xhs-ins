# 原生桌面使用说明

桌面软件直接显示系统控件，不嵌入网页。任务、图片、设置为三个独立页面；原有采集引擎和网页管理入口继续保留。桌面只通过本机接口操作任务，不直接更改任务、断点或图片索引。

## 安装

需要项目原有的 Node.js 22 或更高版本、Python 3.12，以及采集使用的谷歌或微软浏览器。

中文说明：前者运行采集后台，后者运行原生界面；浏览器用于采集和用户主动登录。

苹果在项目目录执行：

```sh
npm ci
python3.12 -m venv .venv-desktop
.venv-desktop/bin/python -m pip install -r desktop/requirements.txt
```

中文说明：安装采集依赖、创建独立桌面环境、安装锁定版本桌面控件库，不修改系统语言环境。

微软在项目目录执行：

```powershell
npm ci
py -3.12 -m venv .venv-desktop
.venv-desktop\Scripts\python -m pip install -r desktop\requirements.txt
```

中文说明：在微软系统创建相同的独立桌面环境并安装依赖。

桌面依赖锁定为 PySide6-Essentials 6.11.2，仅基础控件、网络和测试模块，不安装网页内核。启动脚本不自动安装依赖。

中文说明：使用桌面库精简基础组件，以减少安装体积。

## 启动与退出

- 苹果：双击项目的 `scripts/start-desktop.command`。
- 微软：双击项目的 `scripts/windows/start-desktop.vbs`。

中文说明：两个脚本仅启动项目原生桌面入口，不是安装包，也不启动旧托盘脚本。

首次启动检测并连接后台，没有实例时启动后台；已有实例则沿用它的真实图片目录。默认数据目录为项目下的 `.data`。

中文说明：此隐藏目录保存原有任务数据，不需要迁移或重新创建任务。

再次启动同一数据目录会唤起原窗口。此前已启动但未完成的任务遵循后台既有恢复规则；“待开始”任务不会自动开始。正常采集、打开或最小化窗口均不会默认打开浏览器。需要登录或验证时，在任务操作中主动打开。

- 关闭按钮默认隐藏到托盘或菜单栏，并首次提示后台继续。
- 系统无托盘时，明确选择保留窗口、仅退出界面或退出并停止采集。
- “仅退出界面”保留后台；下次打开重新连接。
- “退出并停止采集”等待保存进度和释放资源，最长约两分钟；停止失败保留窗口并提示。
- 不创建登录自启项，不安装常驻系统服务；电脑休眠时不保证采集继续。

原微软脚本托盘和网页仍可兼容使用，但运行新桌面版时无需同时启动旧托盘。

## 任务与图片

创建任务默认采集最近一年，可选择其他预设或自定义日期。文件导入复用后台的文本、逗号分隔文件、办公文档解析；导入文件不超过十兆字节。手动输入与文件导入最多五百个唯一链接；完整内置七百一十九人名单分五百和二百一十九两批创建。

创建完成均为“待开始”。分页每页三十条，筛选和换页保留勾选；可批量开始、确认删除。删除只删除任务记录，不删除图片。失败任务可重试，部分完成可补采失败图片，已完成和部分完成可采集新增。登录、验证及环境受阻时显示对应恢复操作。

可见任务页活动任务每三秒刷新，空闲每十五秒检查；隐藏或最小化停止轮询，恢复显示立即刷新。其他入口暂停或继续后，界面也会更新。出现存储故障显示安全暂停，阻止继续提交启动类操作；修复磁盘后明确点击继续。

图片根目录只使用后台确认的真实目录，沿用现有布局“图片根目录／账号／图片文件”。每页三十张缩略图，缓存最多六十项。双击打开独立完整图预览，支持适应窗口、原始比例、放大缩小和打开所在目录，不裁成正方形，不重新下载，不提供删除。

仅显示已下载文件，不承诺等同于平台原始上传文件。越界路径和符号链接拒绝读取；损坏或不支持格式明确提示。当前环境没有 AVIF 解码插件，该类图片可能不能预览，但不会修改已下载文件。

中文说明：这种高压缩图片格式是否能预览取决于本机桌面库插件。

为控制内存，编码文件超过六十四兆字节会跳过；解码分配上限一百二十八兆字节，超过三千二百万像素的大图先缩至最长边四千零九十六像素并提示。部分无法在限额内解码的图片会跳过。原始比例代表当前解码图片的一像素对应屏幕一逻辑像素。

## 设置与排错

设置页展示后台状态、真实数据和图片目录，提供依赖检查、默认采集周期、关闭按钮行为和下次启动的图片保存目录。更改目录不会移动旧图片，也不会自动重启后台；需要先明确安全停止后台，再重新打开软件后生效。已有后台运行时仍显示其真实目录。

从旧版升级时，旧后台可能没有返回新版要求的实际数据目录或图片目录，此时新桌面会拒绝连接。请先在旧版界面或原启动入口中显式执行安全停止，等待任务进度保存和后台退出后，再打开新版桌面；新版不会自动停止、重启或接管正在采集的旧后台。

若运行环境不在系统搜索路径，可直接指定可执行文件：

```sh
.venv-desktop/bin/python desktop/main.py --node /absolute/path/to/node
```

中文说明：将示例路径替换为后台运行环境的实际绝对路径。

验证或调试必须使用临时数据目录，并先使用随机端口启动隔离后台，避免与已有实例碰撞：

```sh
node scripts/background.js start --data-dir /tmp/collector-desktop-check --port 0 --json
.venv-desktop/bin/python desktop/main.py --data-dir /tmp/collector-desktop-check
```

中文说明：先启动隔离后台，再让桌面连接相同目录；微软请换成自己的临时目录及对应桌面环境路径。不要把真实任务目录用于开发验收。

## 自动化与实机边界

```sh
QT_QPA_PLATFORM=offscreen .venv-desktop/bin/python -m unittest discover -s desktop/tests -v
npm test
npm run check
```

中文说明：依次运行无显示桌面行为测试、原项目全套测试和项目静态检查。

自动化覆盖真实本机网络成功／失联／超时、真实隔离后台创建待开始和停止、设置保存、任务控件、导入、内置分批、勾选分页、图片边界与缓存、单实例和退出行为。跨平台流水线配置苹果、微软、系统开源桌面三个环境；无显示测试不等于原生实机验收。

苹果原生图形后端已验证：三页渲染、实际第二进程唤起、关闭停轮询、仅退出界面后台存活、重连同一后台、横竖图片和原比例缩放；设置页长路径在默认和缩小窗口下通过原生布局回归。另用全新隔离后台验证窗口安全停止后服务确实退出。

菜单栏托盘的人工点击验收尚未完成；微软原生窗口、托盘与关闭行为未实机验证。无显示测试的窗口行为不代替系统托盘验收。
