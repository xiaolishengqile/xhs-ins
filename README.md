# 公开博主图片采集工具

一个只在本机运行的采集工具，提供原生桌面窗口，支持任务管理、本地完整图片浏览和设置；保留网页管理界面与原微软托盘入口兼容使用。输入小红书或照片墙平台公开博主主页链接和时间范围，按需启动任务后，将图片保存到电脑。

## 主要能力

- 任务先创建为“待开始”，不会因输入链接或导入文件立即搜索。
- 可单独开始任务，也可勾选多个任务批量开始；低占用模式默认全局只采集 1 位博主。
- 每张下载完成后释放响应内存；最后一个采集会话结束后，空闲两分钟回收采集浏览器，登录资料保留。
- 每篇已解析帖子保存独立断点；暂停、退出或重启后复用进度。图片下载失败标记“部分完成”，点击“补采失败图片”重试。
- 已完成任务可以点击“采集新增”：保留原开始日期，将结束日期更新到今天，复用已解析帖子和成功图片。仍需扫描主页，但不会反复打开已解析的详情页。
- 任务列表每页 30 项，全选涵盖所有页；活动任务每三秒刷新，隐藏页面后停止轮询。
- 手动输入和文件导入单次最多支持 500 个唯一链接。
- 内置提供的文档名单中 719 位 Instagram 博主，可一键加载并分两批创建待开始任务。
- 支持文本、逗号分隔文件和 `.docx` 文档；可识别正文、表格及可点击链接。
- 采集周期默认最近一年，并支持最近一周、最近一个月、最近半年和自定义日期。
- 小红书与 Instagram 均只保存图文图片，短视频、纯视频和视频笔记会被过滤。
- Instagram 会从页面提供的多尺寸候选中选择最高分辨率版本；平台未公开原始上传文件时，只能保存其公开提供的最大尺寸图片。
- 临时页面响应失败会自动退避重试；持续被平台拒绝时自动冷却该平台队列，不会继续快速击穿后续任务。
- 单篇已删除或不可访问的帖子会被跳过，已经采集成功的内容仍会保存。
- 普通采集默认在后台静默运行，不会不断打开或抢占浏览器窗口。
- 只有任务明确要求登录或验证时，用户点击“打开登录窗口”才会显示独立浏览器；处理完成后点击“我已处理，继续”。
- 可暂停全部任务并关闭本工具拥有的浏览器，不会关闭或修改用户日常使用的浏览器会话。
- 任务支持取消、重试、单个删除和批量删除；删除任务不会删除已经保存的图片。

## 环境要求

- Node.js 22 或更高版本。
- macOS、Windows 或 Linux 图形桌面环境。
- 已安装 Google Chrome 或 Microsoft Edge。
- 可正常访问目标平台的网络。

## 安装与启动

### 推荐：原生桌面窗口

桌面版使用独立的 Python 3.12 环境与原生控件，复用现有采集后台，不含网页内核。安装、苹果和微软启动入口、图片格式边界及验收状态见 [桌面使用说明](docs/desktop.md)。

中文说明：需要同时安装界面语言运行环境和项目原有的后台运行环境。

安装完成后，苹果双击 `scripts/start-desktop.command`，微软双击 `scripts/windows/start-desktop.vbs`。关闭按钮默认隐藏至托盘，后台继续；需要停机时选择“退出并停止采集”。启动、切换页面和最小化不会自动打开浏览器。

中文说明：以上分别为苹果和微软的原生桌面启动脚本；无需同时启动旧托盘。

### 微软桌面系统：原托盘兼容入口

先安装所需运行环境和浏览器，在项目目录执行一次：

```powershell
npm ci
```

中文说明：按锁定版本安装项目依赖。

之后双击 `scripts/windows/launch-tray.vbs`。托盘启动时不自动打开浏览器；右键可以打开管理界面、暂停或继续采集、停止后台，也可选择登录后启动。

“关闭托盘（后台继续）”不会停止采集；“退出并停止后台”会保存可恢复进度并退出。完整说明见 [微软桌面后台使用说明](docs/windows-background.md)。目前为依赖本机运行环境的托盘版，尚未制作自带运行环境的安装包。

### 各平台通用：独立后台

```bash
npm run background:start
npm run background:status
npm run background:stop
```

中文说明：依次为启动后台、查看后台状态、安全停止后台。后台启动不打开页面；管理页地址为本机 4310 端口。

### 前台调试

在 macOS 上，请打开系统自带的“终端”应用后执行以下命令。不要从受限的编辑器任务进程启动服务，否则系统可能阻止采集浏览器启动。

```bash
npm install
npm start
```

然后打开：

```text
http://127.0.0.1:4310
```

服务只监听本机地址。采集依赖本机浏览器、持久登录资料和本地图片目录，因此部署到 Vercel 等云函数平台时只可查看页面，不能发起采集。

## 使用流程

1. 选择一种链接来源：手动粘贴、导入文件，或点击“加载内置博主（719）”。
2. 检查输入框中的主页链接，并选择采集周期。
3. 点击“加入待采集”。此时只创建任务，不会打开网页或开始搜索。
4. 在任务卡片点击“开始”，或勾选多个待开始任务后点击“开始选中”。
5. 任务在后台静默采集；运行期间仍可继续添加和启动其他任务。
6. 若任务显示“等待人工处理”，先点击“打开登录窗口”，完成登录或验证，再回到任务页点击“我已处理，继续”。同平台任务会一起等待，另一平台仍可继续运行。
7. 若任务显示“运行环境受阻”，请先确认服务从系统终端启动，再点击任一受阻任务的“重新检测并继续”。同平台受阻任务会一起恢复，不需要逐个重试。
8. 点击“打开图片文件夹”查看已保存图片。
9. 需要停止时点击“暂停全部”；正在运行和排队的任务会变为暂停，工具浏览器会关闭。点击“继续全部”后重新排队。

## 图片保存方式

默认保存在当前用户的图片目录下；微软托盘使用系统返回的“图片”目录（包含系统配置的重定向）。下面是苹果系统的示例：

```text
/Users/lijiawei/Pictures/博主图片采集/
└── <博主账号>/
    ├── <博主账号>_000001_点赞123.jpg
    ├── <博主账号>_000002_点赞123.jpg
    └── <博主账号>_000003_点赞未知.webp
```

- 子文件夹使用主页账号名，避免显示昵称变化导致目录分裂。
- 六位序号在同一账号目录内持续递增。
- 同一篇图文的多张图片使用不同序号，并保留同一条笔记的点赞快照。
- 平台未公开点赞数时使用“点赞未知”。
- 已保存过的同一平台、同一账号、同一笔记、同一图片序号不会重复下载。
- 下载后按图片真实内容识别格式和尺寸，不再仅根据网址后缀命名。
- 相同图片即使使用不同网址也只保存一份；最长边不足 1080 像素时，任务卡片会提示仅获得平台预览尺寸。
- 旧版索引会在再次采集时自动补齐图片尺寸与内容摘要；发现更大候选图时会原位升级，不产生重复文件。
- 不生成采集明细表、任务压缩包或汇总压缩包。

## 内部数据

任务状态、登录资料和图片去重索引保存在项目的 `.data` 目录：

```text
.data/
├── browser-profiles/
├── output-index/
├── scheduler.json
└── tasks/
    └── <任务编号>/
        ├── task.json
        └── collection.json
```

图片去重索引同时记录来源地址、真实格式、宽高、文件大小和内容摘要，便于排查低分辨率或重复图片。

采集断点独立保存已解析帖子、待补帖子和失败图片编号，不会随任务列表反复传输。后台实例状态、私有控制凭证和有大小上限的日志保存在数据目录的 `background` 子目录，不应公开上传。迁移电脑时先安全停止后台并备份数据、图片；浏览器登录状态可能受系统加密保护，换电脑后应重新登录。

删除任务只删除对应任务记录。删除 `.data` 会清除任务状态、去重索引和本工具的登录资料，但不会删除 `/Users/lijiawei/Pictures/博主图片采集` 中的图片。

## 已知边界

- 当前开发机已验证独立后台进程和采集逻辑；微软原生托盘、隐藏窗口、命名管道与登录启动仍需目标电脑验收。仓库已提供跨平台自动测试配置，未声称远端测试已执行。
- 低占用不等于零占用；当前实现单任务、低后台优先级和空闲回收，尚未加入按电量/系统负载自动调速或下载带宽硬限制。
- 电脑休眠期间不保证采集继续；本工具不会阻止休眠。正在导航时停止可能需要等待请求结束，异常断电后下次启动可复用已落盘断点。
- 旧任务没有逐帖断点时，首次重试仍需重新扫描；已有图片继续使用原去重索引。不要直接把旧系统的浏览器资料视为跨系统可用登录凭证。

- 只支持公开主页和公开内容，不支持私密账号或好友可见内容。
- 平台页面未公开的数据无法采集；当前文件名只保留点赞快照，不保存收藏数、评论数或原文链接明细。
- 平台页面结构变化后，采集解析规则可能需要调整。
- “最高分辨率”指平台当前网页公开提供的最大候选尺寸，不保证等同于作者上传前的原始文件。
- 验证码和登录墙必须人工处理，程序不会破解或绕过安全机制。
- 下载和使用图片时应遵守平台规则、版权要求和适用法律。
