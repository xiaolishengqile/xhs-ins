# 公开博主图片采集工具

一个只在本机运行的网页工具。输入小红书或 Instagram 公开博主主页链接和时间范围，即可采集范围内的公开图片、标题、发布时间、原文链接以及页面公开的互动数量。

## 主要能力

- 最多同时采集 5 位博主，第 6 个及之后的任务自动等待。
- 任务运行期间，输入框始终可以继续提交新链接。
- 支持最近一周、最近一个月、最近半年和自定义日期。
- 小红书图文笔记下载全部图片，视频笔记保存公开封面。
- Instagram 图片帖子保存公开图片，视频帖子保存公开封面。
- 每个任务独立显示进度，可取消、重试、人工验证后恢复。
- 完成后下载包含图片和 `notes.csv` 数据表的压缩包。
- 任务状态和登录资料保存在本机，应用重启后可恢复未完成任务。

## 环境要求

- Node.js 22 或更高版本。
- macOS、Windows 或 Linux 图形桌面环境。
- 可正常访问目标平台的网络。

## 安装

```bash
npm install
npm run install:browser
```

第二条命令会安装采集所需的浏览器，只需执行一次。

## 启动

```bash
npm start
```

然后打开：

```text
http://127.0.0.1:4310
```

服务只监听本机地址，局域网和互联网中的其他设备无法直接访问。

## 使用流程

1. 粘贴公开博主主页链接。
2. 选择采集周期或填写自定义日期。
3. 点击“开始采集”。
4. 当前任务运行时，可继续粘贴下一位博主链接。
5. 若状态显示“等待人工处理”，在自动打开的采集浏览器中完成登录或验证，再回到网页点击“我已处理，继续”。
6. 任务完成后点击“下载结果”。

小红书和 Instagram 使用独立的持久登录资料。程序不会要求或保存明文账号密码，登录操作由使用者直接在平台页面中完成。

## 数据位置

运行数据默认保存在：

```text
.data/
├── browser-profiles/
└── tasks/
    └── <任务编号>/
        ├── task.json
        ├── notes.json
        ├── media/
        └── result.zip
```

删除 `.data` 会清除任务记录、下载结果和本机浏览器登录状态。

## 测试与检查

```bash
npm test
npm run check
```

真实小红书公开主页只读检查：

```bash
npm run smoke:xhs -- 'https://www.xiaohongshu.com/user/profile/用户编号'
```

该检查只读取主页首屏。如果页面返回卡片但隐藏笔记编号，会明确报告需要人工登录，不会尝试绕过平台验证。

## 已知边界

- 只支持公开主页和公开内容，不支持私密账号或好友可见内容。
- 点赞、收藏和评论数量是采集时的当前快照，不是历史曲线。
- Instagram 不公开任意其他账号的收藏数，因此该字段会留空。
- 页面未显示的点赞或评论数量会留空，不会被写成零。
- 平台页面结构变化后，采集选择器可能需要随版本调整。
- 验证码和登录墙必须人工处理，程序不会破解或绕过安全机制。
- 下载和使用图片时应遵守平台规则、版权要求和适用法律。
