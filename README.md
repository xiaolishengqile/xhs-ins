# 公开博主图片采集工具

一个只在本机运行的网页工具。输入小红书或 Instagram 公开博主主页链接和时间范围，按需启动任务后，将范围内公开图文内容的图片保存到电脑。

## 主要能力

- 任务先创建为“待开始”，不会因输入链接或导入文件立即搜索。
- 可单独开始任务，也可勾选多个任务批量开始；最多同时采集 5 位博主。
- 手动输入和文件导入单次最多支持 500 个唯一链接。
- 内置提供的文档名单中 719 位 Instagram 博主，可一键加载并分两批创建待开始任务。
- 支持文本、逗号分隔文件和 `.docx` 文档；可识别正文、表格及可点击链接。
- 支持最近一周、最近一个月、最近半年和自定义日期。
- 小红书与 Instagram 均只保存图文图片，短视频、纯视频和视频笔记会被过滤。
- 普通采集默认在后台静默运行，不会不断打开或抢占浏览器窗口。
- 只有任务明确要求登录或验证时，用户点击“打开登录窗口”才会显示独立浏览器；处理完成后点击“我已处理，继续”。
- 可暂停全部任务并关闭本工具拥有的浏览器，不会关闭或修改用户日常使用的浏览器会话。
- 任务支持取消、重试、单个删除和批量删除；删除任务不会删除已经保存的图片。

## 环境要求

- Node.js 22 或更高版本。
- macOS、Windows 或 Linux 图形桌面环境。
- 已安装 Google Chrome 或 Microsoft Edge。
- 可正常访问目标平台的网络。

## 安装与启动

```bash
npm install
npm start
```

然后打开：

```text
http://127.0.0.1:4310
```

服务只监听本机地址。采集依赖本机浏览器、持久登录资料和本地图片目录，因此部署到 Vercel 等云函数平台时只可查看页面，不能发起采集。

## 使用流程

1. 选择一种链接来源：手动粘贴、导入文件，或点击“加载内置博主（719）”。
2. 检查输入框中的主页链接，并选择采集周期。
3. 点击“加入待采集”。此时只创建任务，不会打开网页或开始搜索。
4. 在任务卡片点击“开始”，或勾选多个待开始任务后点击“开始选中”。
5. 任务在后台静默采集；运行期间仍可继续添加和启动其他任务。
6. 若任务显示“等待人工处理”，先点击“打开登录窗口”，完成登录或验证，再回到任务页点击“我已处理，继续”。同平台任务会一起等待，另一平台仍可继续运行。
7. 点击“打开图片文件夹”查看已保存图片。
8. 需要停止时点击“暂停全部”；正在运行和排队的任务会变为暂停，工具浏览器会关闭。点击“继续全部”后重新排队。

## 图片保存方式

图片固定保存在：

```text
/Users/lijiawei/Pictures/博主图片采集/
└── <博主账号>/
    ├── <博主账号>_000001_点赞123.jpg
    ├── <博主账号>_000002_点赞123.jpg
    └── <博主账号>_000003_点赞未知.webp
```

- 子文件夹使用主页账号名，避免显示昵称变化导致目录分裂。
- 六位序号在同一账号目录内持续递增。
- 同一篇图文的多张图片使用不同序号，并保留同一条笔记的点赞快照。
- 平台未公开点赞数时使用“点赞未知”。
- 已保存过的同一平台、同一账号、同一笔记、同一图片序号不会重复下载。
- 不生成采集明细表、任务压缩包或汇总压缩包。

## 内部数据

任务状态、登录资料和图片去重索引保存在项目的 `.data` 目录：

```text
.data/
├── browser-profiles/
├── output-index/
├── scheduler.json
└── tasks/
    └── <任务编号>/
        └── task.json
```

删除任务只删除对应任务记录。删除 `.data` 会清除任务状态、去重索引和本工具的登录资料，但不会删除 `/Users/lijiawei/Pictures/博主图片采集` 中的图片。

## 已知边界

- 只支持公开主页和公开内容，不支持私密账号或好友可见内容。
- 平台页面未公开的数据无法采集；当前文件名只保留点赞快照，不保存收藏数、评论数或原文链接明细。
- 平台页面结构变化后，采集解析规则可能需要调整。
- 验证码和登录墙必须人工处理，程序不会破解或绕过安全机制。
- 下载和使用图片时应遵守平台规则、版权要求和适用法律。
